# 合成数据测试

## 目的与范围

测试覆盖轮廓关键点、相机几何和合成演示。输入均由代码生成，无需外部数据或 Isaac Sim。

## 文件放置

将本套件的 tests/、scripts/、docs/ 合并到 pose-estimation-lab-lite 仓库根目录，保留已有文件。不要把 public-test-kit 整个文件夹嵌套放进仓库。测试使用现有 src/ 中三个公开模块，无须增加原项目代码。

## 运行

在仓库根目录执行：

```text
python -m pip install -r requirements.txt
python scripts/run_public_tests.py
```

也可执行完整仓库测试：

```text
python -m unittest discover -s tests -v
```

退出码 0 表示全部通过，1 表示测试失败，运行脚本返回 2 表示缺少公开源码。导入或依赖错误也会导致非零退出。脚本只在终端显示公开合成测试状态，不生成测试报告文件；演示测试产生的合成图片放在临时目录并自动清理。

## 测试案例与判据

| 案例 | 判据 |
|---|---|
| 空掩膜 | 返回形状 (0, 2) 的轮廓 |
| 多连通区域 | 选择面积更大的矩形轮廓 |
| 已知正方形转角 | 四个顶点均为 90 度 |
| 平移不变性 | 平移轮廓不改变局部转角 |
| 三种筛选模式 | 返回点数受限，满足最小间距且响应正确 |
| 非法轮廓参数 | 单通道、窗口、模式、百分位错误按约定拒绝 |
| 刚体求逆 | 非单位旋转和平移的变换复合为单位阵，点可往返恢复 |
| 理想内参 | 90 度垂直视场角得到独立手算的焦距和主点 |
| 针孔投影 | 已知三维点投影与手算值一致，非正深度返回 NaN |
| 非法相机参数 | 非正分辨率和边界视场角被拒绝 |
| 合成演示 | 两次生成像素一致，输出相对输入发生变化 |

## 未覆盖的内容

内部数据和验收结果不随测试发布。运行脚本不保存报告。

当前案例不覆盖实际相机标定、畸变、遮挡鲁棒性、PnP、模型推理、仿真集成或性能。演示测试验证文件与确定性，不证明每个标注位置都正确。多阈值案例只验证当前筛选契约，不证明实现了高、中、低分组。
