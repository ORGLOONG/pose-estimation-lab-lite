# 模块范围

本仓库保留轮廓关键点提取、相机几何和合成示例，用于独立运行和测试。

## 模块与测试

| 模块 | 内容 | 测试重点 |
|---|---|---|
| contour_keypoints | 轮廓提取、转角计算、阈值筛选和距离抑制 | 已知角度、平移不变性、点间距和边界输入 |
| camera_geometry | 刚体变换、内参和针孔投影 | 变换往返、解析投影值和无效深度 |
| visualization | 合成轮廓和立方体投影示例 | 图片尺寸、重复性和输出变化 |

测试使用人工构造的几何样本，不依赖仿真运行环境。内部场景、配置、数据和验收结果不包含在仓库中。

## 方法来源

轮廓关键点流程的来源和改编说明见根目录 NOTICE，许可沿用现有许可文件。

## 限制

本仓库不包含完整位姿求解链路。合成测试用于检查模块行为，不代表真实场景的精度、鲁棒性或性能评估。
